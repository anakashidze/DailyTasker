# TaskNext 1.4.0

- Home navigation gestures: swipe right opens Tasks; swipe left opens Settings.
- History can delete individual records and clear all records.
- Replaced user-facing Color with reusable Groups.
- Built-in groups: Task (indigo/check), Home (brown/home), Health (green/heart), Work (blue/briefcase).
- Custom groups can be created with a name, icon, and color and are saved locally.
- New tasks default to Remind me ON and Use default time ON.
- Reminder controls blend into the dialog background instead of sitting in a separate panel.
- Task cards are opaque so hidden swipe actions do not show until the card is actually swiped.
- Launcher icon was optically re-centered and redesigned as a combined check + next arrow mark.
- Database migration 3 -> 4 adds the group icon field while preserving existing tasks.
