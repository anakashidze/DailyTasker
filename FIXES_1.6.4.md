# TaskNext 1.6.4

- New-task dialogs now autofocus the **Title** field.
- The software keyboard is requested automatically, so typing can start immediately.
- This applies to tasks opened from the normal **Add task** action and from the Home **swipe-down / pull-to-add** gesture, because both use the same add-task dialog.
- Editing an existing task does **not** force focus into the title field.
